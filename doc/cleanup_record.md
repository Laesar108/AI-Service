# 파일 정리 기록

정리일: 2026-10-21. 최초 파일과 현재 사용 파일을 남기고 중간 산출물을 프로젝트 밖으로 정리했다.

## 보존

- 최초 평가 기준 코드 `eval/baseline/`와 최초 정식 응답 `eval/results/before-live/` (33개).
- 현재 실행 코드 `agent/`, 서버, 화면, 현재 데이터·Runbook·검색 인덱스.
- 현재 응답 `eval/results/current/` (48개): 원래 최신 평가의 after 응답/채점 파일과 바이트가 동일하다.
- 고정 평가 자료, 검색 평가 자료, 원래 매뉴얼·질문·이미지, 최초 응답·그래프, 현재 그래프·화면, 테스트.
- `.env`, `.env.example`, `.venv/`, 세션 DB는 정리 대상에 포함하지 않았다. 이번 작업은 `.env`를 읽지 않았다.

## 정리

- 중간 코드 사본 2개: `baseline_pre_rag`, `baseline_pre_selective`.
- 예비/중간 결과 폴더 14개와 이전 비교 요약·검증 산출물. 최신 폴더는 current 자료를 추출한 뒤 정리했다.
- 단계별 평가 도구를 `run_evaluation.py` → `score_responses.py` → `summarize_results.py` 한 세트로 통합했다.
- 중간 그래프·화면·단계별 보고서를 정리하고 현재 설명은 `improvement_report.md`로 통합했다.
- 백업한 기존 파일은 총 170개이며, 교체 전 평가 도구와 문서도 포함한다.

## 비교 기준

이제 실행 도구의 before는 **최초 원본**, after는 **현재 RAG/선택적 멀티에이전트**다. 이전 최적화 실험의 before는 중간 버전이었다. 그 비교 수치를 최초 대비 개선율로 바꾸지 않았다.

기존 두 결과의 실행 시점·계측·채점 지침이 달라 새로운 동일 조건 비교는 [평가 안내](../eval/README.md)의 명령으로 수행한다. 이번에는 파일 정리와 오프라인 실행 검증만 했으며 API 평가를 재실행하지 않았다.
